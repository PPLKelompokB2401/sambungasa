## 2. Kebutuhan Non-Fungsional (Non-Functional Requirements)

| Requirement ID | Aspek | Persyaratan | File / Implementasi Terkait | Status | Bukti & Evaluasi |
|:---:|---|---|---|:---:|---|
| **NF-01** | **Performa Koneksi Terbatas** | Ringan, pemuatan cepat, pagination pada list, asset teroptimasi. | - `public/css/sambungasa.css` (hanya ~16KB murni)<br>- Eloquent pagination 10-15 item/halaman. | `DONE` | Bebas dari framework CSS berat (Tailwind runtime/bundler dihindari). Render halaman rata-rata < 100ms di local server. |
